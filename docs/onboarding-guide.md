# costmgr Onboarding 가이드

**Version:** v1.0.0
**Last Updated:** 2026-08-22

costmgr를 시작하시기 전에 이 가이드를 읽고 핵심 기능을 익혀보세요.

---

## 1. 시작하기

1. [costmgr.kr](https://costmgr.kr)에 접속합니다.
2. 회원가입을 진행합니다 (이메일 + 비밀번호).
3. 회사 정보 (회사명, 산업군)를 입력합니다.
4. 첫 로그인 후 대시보드가 표시됩니다.

## 2. 첫 대시보드

대시보드에는 다음 5종 위젯이 표시됩니다.

- 원가 추이 차트
- ABC/TDABC 분석 요약
- AI 인사이트
- 월간 마감 진행률
- 백업 상태

위젯은 자유롭게 추가/제거/순서 변경이 가능합니다.

## 3. 데이터 입력 6종

costmgr는 6종 데이터를 입력받아 원가를 계산합니다.

| 카테고리 | 설명 | 권장 빈도 |
|---------|------|----------|
| 생산 (Production) | 제조량, 작업 시간 | 매일 |
| 주문 (Orders) | 수주 내역 | 매일 |
| 판매 (Sales) | 매출 내역 | 매일 |
| 매입 (Purchases) | 매입 내역 | 매일 |
| 경비 (Expenses) | 판관비, 제조간접비 | 매주 |
| 노무 (Labor) | 임금, 근무시간 | 매월 |

## 4. ABC/TDABC 분석 활용

ABC(활동기준원가) + TDABC(시간동인 원가배분)를 결합하여 정확한 원가를 산출합니다.

- **ABC**: 활동을 기준으로 원가를 배분
- **TDABC**: 각 활동의 실제 소요 시간을 측정하여 원가 배분
- **분석 결과**: 제품별/서비스별 원가, 손익분기점, 마진율

자세한 내용은 `docs/abc-tdabc-guide.md` (별도 문서) 참조.

## 5. AI 인사이트 활용

AI 인사이트는 다음 3종을 제공합니다.

1. **비용 절감 후보**: 원가 절감 기회를 자동 감지
2. **이상 패턴**: 비정상적인 원가 변동 탐지
3. **예측**: 다음 기간의 원가 예측

> ⚠️ AI 인사이트는 참고용이며, 최종 의사결정 책임은 사용자에게 있습니다.

## 6. 보안 / 2FA 설정

계정 보안을 위해 2FA(2차 인증) 설정을 권장합니다.

1. 우측 상단 프로필 → 보안 설정
2. TOTP 앱 (Google Authenticator, Authy 등) 설치
3. QR 코드 스캔
4. 6자리 코드 입력하여 활성화

## 7. 자주 묻는 질문 (FAQ)

자주 묻는 질문은 [FAQ 문서](./faq.md)를 참조하세요.

## 8. 지원팀 연락

문제가 해결되지 않으면 다음 채널로 문의하세요.

- **이메일:** support@bizup.kr
- **응답 시간:** P1 4시간 / P2 24시간 / P3 72시간
- **긴급:** P1 이슈 (서비스 장애) → 즉시 응답
