# 고객 지원 (Customer Support)

**Version:** v1.0.0
**Last Updated:** 2026-08-22

costmgr는 다음 채널로 고객 지원을 제공합니다.

---

## 1. 연락 채널

- **이메일:** support@bizup.kr
- **In-app Help Widget:** 우측 하단 floating button
- **문서:** docs/ 디렉토리 (ko-KR, 영문)
- **FAQ:** [faq.md](./faq.md)

## 2. 자주 묻는 질문 (FAQ)

자주 묻는 질문은 [faq.md](./faq.md) 문서를 참조하세요. ABC vs TDABC 차이, 2FA 설정, 백업 정책 등 10가지 주제를 다룹니다.

## 3. 응답 시간

- **이메일:** 24시간 이내 첫 응답 (영업일 기준)
- **In-app Help Widget:** 실시간 (평일 09:00~18:00 KST)
- **긴급 (P1):** 4시간 이내

## 4. SLA (Service Level Agreement)

| 우선순위 | 정의 | 응답 시간 |
|---------|------|----------|
| P1 (긴급) | 서비스 장애 / 데이터 손실 | 4시간 이내 |
| P2 (높음) | 핵심 기능 오작동 | 24시간 이내 |
| P3 (보통) | 일반 문의 / 개선 요청 | 72시간 이내 |

## 5. Escalation 절차

- **P1 이슈:** 즉시 대응 → CEO 보고
- **P2 이슈:** 24시간 내 해결 → CTO 보고
- **P3 이슈:** 일반 지원 큐에서 처리

## 6. 외부 지원 링크

- **Status Page:** status.bizup.kr (예정)
- **Documentation:** docs/ 디렉토리
- **GitHub Issues:** github.com/costmgr/issues (private)
- **Community:** community.bizup.kr (예정)
