## 2. 부수 효과로 깨진 테스트 1건 수정 (실제 결함)

`tests/api/m10_ai/test_promote_endpoint.py::test_promote_envelope_is_annotated_union`

- 증상: UP007 적용 후 TypeError 로 실패.
- 원인: `PromoteEnvelope` 내부 타입이 `typing._GenericAlias`(Union[...]) 에서
  `types.UnionType`(X | Y) 로 바뀌었고, 테스트가 쓰던 `get_type_hints()` 는
  모듈/클래스/함수만 받으므로 후자를 거부한다.
- 범위: 검사 방법만 깨졌고 계약은 정상이다. Pydantic v2 discriminated union
  런타임 동작과 FastAPI 앱 임포트는 영향 없음 (동일 실행에서 나머지 711건 통과).
- 기존 테스트의 약점: `get_type_hints()` 결과인 `hints` 를 전혀 사용하지 않는
  죽은 코드였고, 실제 단언은 `"Annotated" in str(...)` 문자열 검사뿐이라
  독스트링이 주장하는 불변식을 검증하지 못했다.
- 수정: `get_args()` 기반 introspection 으로 교체하여 불변식을 실제로 검증한다.
  (1) Annotated[union, FieldInfo] 2-튜플 구조
  (2) union variant 7개 = 1 success + 6 typed error (AD-7 strict invariant)
  (3) FieldInfo.discriminator == "status"
  `get_args()` 는 Union[...] 과 X | Y 양쪽 표기에 모두 동작하므로 표기법에
  중립적이다.
