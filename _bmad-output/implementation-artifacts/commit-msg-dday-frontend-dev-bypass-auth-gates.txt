  `sb-access-token` 쿠키 존재 여부만 검사 → 쿠키 없으면
  `redirect("/ko-KR/login")` → HTTP 307.
- 결과: 백엔드 bypass 가 작동해도 프론트엔드 gate 가 먼저 catch.
- 결정 wire 보존: cookie-less dev bypass 환경에서 페이지 단위 gate 가
  SPA 동작을 차단. Production 안전은 백엔드 APP_ENV=production 가드와
  frontend NEXT_PUBLIC_MVP_DEV_BYPASS 미설정 두 곳에서 보장.
